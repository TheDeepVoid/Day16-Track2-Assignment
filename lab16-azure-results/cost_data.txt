The two rows above are the values returned by a successful query. Note the
Cost Management API aggressively rate-limits (HTTP 429) when queried repeatedly
in a short window, so re-running the query may need a pause between calls:

  az account get-access-token --resource https://management.azure.com/ --query accessToken -o tsv
  curl -s -H "Authorization: Bearer $TOKEN" \
    "https://management.azure.com/subscriptions/<SUB_ID>/providers/Microsoft.CostManagement/query?api-version=2023-03-01" \
    -H "Content-Type: application/json" \
    -d '{"type":"ActualCost","timeframe":"MonthToDate","dataset":{"granularity":"Daily","aggregation":{"totalCost":{"name":"Cost","function":"Sum"}},"grouping":[{"type":"Dimension","name":"ResourceGroup"}]}}'
